# João Gabriel — Portfolio
Portfolio pessoal em React + TypeScript + Vite, com visual Dark Editorial (fundo escuro + acento laranja).

## Stack
React 19 + TypeScript
Vite (build)
CSS puro com design tokens (variáveis)
Desenvolvimento
bash npm install npm run dev # servidor local com hot reload npm run build # gera a pasta dist/ (produção)

## Deploy
Publicado no Vercel com CI automático: todo git push na branch main gera build + deploy.

## Site: <https://jotatw-portfolio.vercel.app>
